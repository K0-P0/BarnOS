# BarnOS

**Your digital homestead.** BarnOS is an open-source ecosystem of local-first tools that strips away corporate cloud dependency — finance, fleet, hardware security, and property telemetry, all running on your own hardware.

**Website:** https://k0-p0.github.io/BarnOS/

## Projects

- **[Monolith](https://k0-p0.github.io/Monolith/)** — self-hosted finance & fleet management. Python backend, runs on a dedicated bare-metal "Black Box" node. No cloud, no subscriptions, your data never leaves your network.
- **SkeletonKey** — hardware security key with FIDO2/WebAuthn, fingerprint auth, and an on-device encrypted password manager. No cloud account, no companion app.

## Principles

- **Local-first** — everything runs on your hardware, in your space.
- **Zero-trust** — nothing external is assumed trustworthy.
- **Self-sufficient** — solar-ready, battery-backed, keeps working when the internet doesn't.

The website source lives on the [`gh-pages`](https://github.com/K0-P0/BarnOS/tree/gh-pages) branch.
