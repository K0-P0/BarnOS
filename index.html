Active Projects

BarnOS is built as distinct, independent modules — each one solves a specific problem without depending on a corporate cloud.

Monolith

V7.2 — Released Python · Flask · Docker

Monolith is BarnOS's self-hosted personal finance dashboard. Built on a Python / Flask / Gunicorn stack with SQLite, it runs on Docker, bare metal, an LXC container, or any VM — no SaaS subscriptions, no data leaving your network.

What it does

  • 19 plugins — paychecks, bills, budgets, debt payoff, garage & more
  • Per-user Fernet encryption at rest
  • Mandatory TOTP 2FA with backup codes
  • Full JSON export & import for backups
  • Admin panel with global plugin controls
  • One-command Docker install (ghcr.io)

The Black Box

Monolith runs on the Black Box — a dedicated bare-metal node that serves as the local brain for Monolith's data and services. If the internet goes down, Monolith keeps running.

Visit the Monolith site →

The Monolith dashboard. Real interface, invented numbers — this is a throwaway demo vault, not anyone's finances.

NoMad

Beta Testing USB · Portable

NoMad is Monolith on a USB stick. Plug it into any Windows or Linux PC, run one script, and Monolith is live in your browser — real work, zero installs. When you're done, pull the stick and your data leaves with you.

No-trace by design

  • Localhost-only — never visible to the network
  • Single-use launch token, fresh session key every boot
  • Auto-shutdown ~25 seconds after the tab closes
  • Browser told to clear site data on the way out

Runs anywhere

The stick bundles its own portable Python runtime, so the host PC needs nothing installed. Tested end-to-end on both Windows and Linux, with plain or fully encrypted stick formats. A pre-built NoMad stick is the next Monolith milestone.

Read more on the Monolith site →

SkeletonKey

Active Development Hardware · Embedded

SkeletonKey is the security and access control arm of BarnOS. It's a self-contained hardware identity device — a physical vault for your passwords, cryptographic keys, and authentication credentials that requires no cloud, no app, and no external service.

Key features

  • FIDO2 / WebAuthn / TOTP
  • Fingerprint-first authentication
  • Built-in encrypted password manager
  • USB-C, NFC, optional BLE
  • Tamper-resistant self-wiping enclosure
  • No cloud or app required

Core hardware

  • Microchip ATECC608B secure element
  • Nordic nRF52840 BLE SoC
  • NXP PN7160 NFC controller
  • 3.7V Li-Po battery
  • 1Gbit encrypted NAND flash

Sentry

V0.1 — Released Rust · CLI

Sentry is BarnOS's security auditor — a dead-simple command-line tool for homelabs and self-hosted game servers, written in Rust. It checks your machines against baseline security practices and groups findings by trust zone, because a private NAS and a public game server want opposite things. No account, no telemetry, nothing phoning home.

What it checks

  • SSH hardening — root login, password auth, fail2ban
  • Firewall default-deny inbound
  • Docker exposure — open bindings, privileged containers
  • Disk encryption at rest
  • Automatic updates & pending patches
  • Game servers — RCON exposure & plugin integrity

Two halves, one picture

sentry watch runs on the machine itself and reads ground-truth local state. sentry probe (coming in v0.2) scans from outside and sees exactly what an attacker sees. Neither can be fooled the same way — a full picture needs both.

Mission

What is BarnOS?

BarnOS is an open-source ecosystem of modular tools built around one idea: you should own your digital life the same way you own your land.

The Problem

In today's tech landscape, you don't really "own" the software or hardware you buy. It's all tied to subscriptions, external servers, and companies harvesting your data.

Your financial software phones home. Your security cameras upload to someone else's cloud. Your authentication depends on a corporation that can lock you out, go bankrupt, or sell your data tomorrow.

BarnOS flips the script.

Core Principles

Total Data Ownership

Your financial data (Monolith), security infrastructure (SkeletonKey), and property telemetry belong strictly to you. No corporate servers. No paywalls. No data harvesting.

Infrastructure Resilience

If the internet goes down, your home, tools, and automation keep running. The brain is on your bare metal — not in a data center hundreds of miles away.

True Privacy

Self-hosted behind your own firewall, local DNS, and reverse proxies. No telemetry. No tracking. No big tech baked into your operating environment.

Physical Integration

Network bridges link physical structures — barns, workshops, security cameras — back to the core system. Your digital and physical world run as one.

Architecture

BarnOS is broken into distinct, independent modules — not one massive tangled codebase. Each module owns its own stack, its own hardware, and its own data.

Edge Nodes

Raspberry Pi Zero 2 W + ESP32 co-processors tracking solar telemetry, sensors, and job site equipment.

Core (Black Box)

Bare-metal node running Monolith — the finance dashboard and its local services. Runs completely offline if needed.

Security (SkeletonKey)

Hardware authentication and access control. A physical device that holds the cryptographic keys to the ecosystem.

Audit (Sentry)

Baseline security checks across every host, grouped by trust zone. Runs on your schedule, reports only to you.

"It is about treating your digital life exactly like a physical homestead: self-sufficient, heavily fortified, and completely independent. You aren't just building a home lab — you're building a digital fortress where you hold the only keys."

Sentry is a free, open-source security auditing tool for homelabs and self-hosted game servers, written in Rust. Run sentry watch on a machine and it checks SSH hardening, firewall policy, Docker exposure, disk encryption, and pending updates — plus game-server specifics like RCON exposure and plugin integrity. Findings are grouped by trust zone (internal vs public) so you can spot when a public server is bridged into your private network. No account, no telemetry, and nothing phones home.
